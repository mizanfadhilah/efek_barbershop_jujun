# Efek BarberShop Jujun

Website company profile responsif dengan HTML, CSS, dan JavaScript vanilla.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser (atau gunakan Live Server di VS Code).
3. Koneksi internet diperlukan untuk font Google dan gambar Unsplash.

## Sebelum dipublikasikan
- Di `script.js`, ubah `WHATSAPP_NUMBER` menjadi nomor WhatsApp bisnis yang benar dalam format internasional tanpa `+`, spasi, atau tanda hubung.
- Di `index.html`, ganti alamat contoh dan nomor cabang dengan data resmi.
- Periksa dan sesuaikan harga contoh pada objek `prices` di `script.js`.
- Ganti foto Unsplash jika ingin memakai foto haircut asli milik bisnis.
- Klaim statistik di hero diberi catatan sebagai contoh; sesuaikan dengan data aktual atau hapus.

Fitur: navigasi mobile, filter gaya rambut, kategori harga dewasa/anak, formulir booking, prefill haircut/cabang, validasi tanggal, dan penyusunan pesan WhatsApp.
